# Phase 2: Redirection and Pipe

이 단계에서는 쉘에서 파이프(`|`) 기능을 지원하도록 기능을 확장했습니다.  
목표는 한 명령어의 출력을 다른 명령어의 입력으로 전달하는 기능을 구현하는 것이었습니다.

## 구현한 기능

- `ls | grep something`과 같이 명령어 사이에 파이프 사용 가능
- 여러 개의 파이프 연결도 지원 (`cat | grep | sort`)
- 각 명령어마다 새로운 프로세스를 생성
- `pipe()`, `dup2()`를 사용해 입력/출력을 연결
- 파이프 라인 전체를 하나의 프로세스 그룹으로 관리
- 마지막 명령이 종료될 때까지 부모 프로세스는 대기

## 내부 구조

- 파이프 단위로 명령어를 나누고
- 각각의 프로세스를 생성한 후
- 표준 입력/출력을 파이프로 재지정한 뒤 `execvp()` 실행

## 주요 학습 포인트

- `dup2()`를 통해 파이프 연결을 수동으로 설정하는 과정에서 입출력 흐름을 시각적으로 이해함
- 여러 개의 프로세스가 협업하여 하나의 명령어 체인을 구성한다는 개념을 체득
- 자식 프로세스별로 파이프를 정확히 닫지 않으면 데드락이나 출력 누락이 발생할 수 있음을 경험함
